## 🌟 Overview

**Gean Memory Vault** is a lightweight, zero-dependency personal dashboard designed to store, showcase, and reference technical snippets, AI prompt templates, SQL formulas, deployment checklists, and keyboard shortcuts. 

Built with **vanilla HTML, modern CSS, and clean JavaScript**, it requires no databases or build steps. You can write your custom cards directly in static HTML, and the client-side JavaScript engine automatically parses your tags, recalculates active statistics, updates relative dates, and powers instant keyword searches.

---

## ✨ Key Features

- 🎨 **Dark Neon Glassmorphism UI:** Sleek, modern dashboard design with vibrant gradient accents and glassmorphic card effects.
- 📱 **Adaptive Mobile Drawer Interface:** Complete responsiveness with slide-out navigation and calendar drawers on mobile and tablet devices.
- ⚡ **Zero-Dependency Architecture:** Pure HTML5, CSS3, and Vanilla JavaScript—no external frameworks or heavy runtimes.
- 🔍 **Instant Live Search & Keyboard Shortcuts:** Instant search filtering across title, description, code snippets, and tags, with global `⌘K` / `Ctrl + K` quick-focus.
- 🏷️ **Dynamic Category & Tag Filtering:** Switch between `PROMPT`, `FORMULA`, `STEP`, `KEY`, and `NOTE` or click any hashtag chip to filter cards.
- ⏱️ **Real-Time Relative Dates:** Calculates `(Current Date) - (Card Date)` directly from your HTML `data-date` attribute and auto-updates every 60 seconds (e.g., *2h ago*, *Yesterday*, *4d ago*).
- 🧩 **Pre-styled Custom Card Elements:** Drop-in styling classes for code blocks, checklist steps, key combinations, structured data tables, and image previews.
- 🌓 **Theme Toggle:** Dark and Light mode options with persistent smooth transitions.
